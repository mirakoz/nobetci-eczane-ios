## 2025-05-15 - [Improving Search & Accessibility with Native Modifiers]
**Learning:** For long lists in SwiftUI sheets, `.searchable` provides a native, accessible way to filter content without cluttering the UI. Pairing this with `contextMenu` for "Copy" actions adds power-user utility while keeping the primary UI clean.
**Action:** Always consider `.searchable` for any list exceeding 10-15 items and use `UIPasteboard` for quick data extraction.
